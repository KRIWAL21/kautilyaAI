# Chanakya-Astra — KautilyaAI Broker Network

Private monorepo for the KautilyaAI / Chanakya-Astra platform.

## Project Structure

| Folder | Description |
|--------|-------------|
| `chanakya-final` | Main Chanakya AI backend/frontend (chanakya.4.0) |
| `Kautilya-astra-service` | Kautilya Astra microservice |
| `Kuatilya-broker` | Broker network frontend (Vue + Vite) |
| `Kautilyaflows_n8n` | n8n automation flows |
| `n8n_flows` | Additional n8n workflow exports |
| `real-estate-microsite-vida-new` | Vida real estate microsite |
| `Vida microsite` | Vida microsite assets |
| `roffr` | Roffr sub-project |
